# 05 통계 — 연도 아카이브

상태: **사용자 검토 완료 (2026-10-08)**. 기존 제품 스펙 05절·D2·D3·D4·D7을 상세화한다.
사용자가 문서 확인 후 구현 플랜 작성을 요청했다. 구현은 플랜 검토 후 진행한다.

## 1. 목적과 범위

사용자가 한 해 운동의 누적량·월별 흐름·근력/유산소 구성·요일 습관·부위 빈도를 돌아보는 화면이다.
홈은 최근 운동과 축적을 보여주고, 통계는 **선택한 연도 전체**를 보여준다.

기존 확정 사항:

- 연도를 바꾸면 잔디·요약·차트·배지가 함께 바뀐다.
- 운동 횟수와 부위 빈도는 세션 수로 센다. 잔디는 하루 한 칸이다.
- 차트는 통계 탭에 둔다. 전환 횟수는 표시하지 않는다.
- 부위 태그가 없으면 부위 섹션을 숨긴다.

이번 상세 스펙에서 확정한 추가 결정:

- 연도 선택지는 현재 연도와 기록이 있는 과거 연도만 제공한다.
- 주 평균은 현재 연도는 오늘까지, 과거 연도는 그 해 전체 기간으로 계산한다.
- 월별·요일별 막대는 세션 수를 표시한다.
- 마일스톤은 선택한 연도의 세션 수 기준으로 10·25·50·100·200·300·500회를 둔다.
- 연 잔디는 7행과 실제 필요한 주 열 수를 사용한다. 고정 53열로 자르지 않는다.

대상은 iOS 17 이상 HaruchiFit 통계 탭이다. 기록 편집·상세 진입·차트 드릴다운,
전년 비교·목표 설정·HealthKit 추가 쿼리·저장 모델 변경은 범위에 포함하지 않는다.

## 2. 화면 구성

기존 다크 팔레트와 화면 여백을 따른다. 상단 제목은 `통계`이며 한 화면에서 세로로 스크롤한다.
콘텐츠 순서는 다음과 같다.

| 순서 | 영역 | 표시 내용 |
|---|---|---|
| 1 | 연도 선택 | `2026 · 2025 · 2024` 형태의 가로 선택 버튼 |
| 2 | 연 잔디 | 선택 연도 전체 날짜, 월 눈금 `1 · 4 · 7 · 10 · 12월` |
| 3 | 연 요약 | 운동 횟수 / 누적 시간 / 주 평균, 3칸 |
| 4 | 월별 운동 | 1~12월 세션 수, 12막대 |
| 5 | 운동 구성 | 근력·유산소 시간 비율 바와 범례 |
| 6 | 요일 패턴 | 월~일 세션 수, 7막대 |
| 7 | 운동 부위 | 태그한 세션 수, 가로 막대 |
| 8 | 마일스톤 | 달성한 배지와 잠긴 다음 목표 하나 |

연도 선택은 콘텐츠 상단에 있으며 별도 고정 헤더는 만들지 않는다.
선택한 연도는 브랜드 오렌지로 구분한다. 선택지는 내림차순이며 많아지면 가로 스크롤한다.
단일 연도여도 해당 연도를 표시한다.

연 요약 라벨은 현재 연도에서 `올해 운동`·`올해 누적`·`주 평균`,
과거 연도에서 `연간 운동`·`연간 누적`·`주 평균`이다.
숫자 예시는 `142회`·`118.0시간`·`주 3.4회`다.

## 3. 연도와 날짜 경계

초기 선택은 현재 연도다. 선택지는 현재 연도와 저장된 기록의 과거 시작 연도다.
기록이 없는 중간 연도는 만들지 않는다. 미래 연도 기록은 선택지에 포함하지 않는다.

연도 소속은 `startedAt`을 `Calendar.current`로 해석한 연도다.
선택 연도 시작 이상·다음 연도 시작 미만인 기록을 사용하며, 현재 연도는 시작 시각이
현재 시각 이하인 기록만 집계한다. 자정을 넘긴 운동은 시작한 날·월·연도에 전부 귀속된다.
워치·HealthKit import·수동 기록을 같은 규칙으로 포함한다.

사용자가 다른 탭에 갔다 돌아와도 현재 선택을 유지한다. 앱 프로세스 재시작 시에는 현재 연도로 시작한다.
앱 활성화 시 날짜와 데이터를 다시 계산한다. 연도가 넘어가면 현재 연도 선택지를 추가하되 사용자가
선택했던 연도를 유지한다. 삭제로 선택한 과거 연도의 마지막 기록이 사라지면 현재 연도로 돌아간다.

## 4. 연 잔디

농도는 기존 `GrassAggregator`·`GrassIntensity.byTime` 결과를 그대로 사용한다.
하루 여러 세션은 시간을 합산하고, 세션이 있지만 시간이 0이면 최소 농도다.
현재 시간 기준 컷은 30·60·90분이며 정확히 컷에 도달하면 다음 단계다.
통계만의 별도 농도 기준은 만들지 않는다.

7행, 날짜는 위에서 아래로 진행하고 다음 열로 넘어간다. 주 시작은 기존 홈처럼
`Calendar.current`의 주 경계를 따른다. 첫 열은 1월 1일이 포함된 주,
마지막 열은 12월 31일이 포함된 주다. 연도 밖 날짜 위치는 투명한 빈 자리로 남겨
해당 연도의 날짜와 구분한다. 윤년을 포함해 모든 날짜를 한 번씩 표시한다.

제품 스펙의 `53주 × 7일`은 1년 전체 잔디를 뜻한다. 날짜 배열을 371칸으로 자르지 않는다.
주 시작과 윤년 배치에 따라 54열이 필요하면 54열을 사용한다.
구현 완료 문서 갱신 때 제품 스펙 05절에도 이 규칙을 반영한다.

연 잔디는 가로 스크롤한다. 현재 연도는 오늘이 포함된 열, 과거 연도는 연초에서 시작한다.
오늘은 고정 테두리로 표시하며 현재 연도의 미래 날짜는 빈 칸에 opacity 0.3을 적용한다.
월 눈금은 해당 월 1일의 열 아래 배치하고 그리드와 함께 스크롤한다.
아래에 `적음`부터 `많음`까지 기존 4단계 농도 범례를 둔다.
칸 탭 동작과 날짜별 상세 팝업은 이번 범위에 없다.

## 5. 연 요약과 주 평균

- 운동 횟수: 선택 연도 레코드 수. 같은 날 두 운동이면 2회다.
- 누적 시간: 선택 연도 `totalSeconds` 합계. 1시간 미만은 정수 분, 이상은 소수 첫째 자리 시간.
- 주 평균: 세션 수 ÷ (집계 기간의 달력 날짜 수 ÷ 7), 소수 첫째 자리로 표시한다.

현재 연도의 집계 기간은 1월 1일부터 오늘까지 양끝을 포함한다.
과거 연도는 1월 1일부터 12월 31일까지 365일 또는 366일이다.
첫 기록일부터 세지 않는다. 기록을 늦게 시작했거나 쉬었던 기간도 연간 습관에 포함하기 때문이다.
날짜 수는 달력 날짜 차로 계산하여 서머타임에 따른 23/25시간을 일수로 오인하지 않는다.
1월 1일에는 분모가 1/7주이며, 1회라면 `주 7.0회`로 표시된다.
주 평균 옆 정보 버튼은 `1월 1일부터 오늘까지의 기록을 주 단위로 환산해요.`를 보여준다.
과거 연도에서는 `선택한 연도 전체의 기록을 주 단위로 환산해요.`를 보여준다.

## 6. 차트 집계와 표시

### 월별 운동

제목 `월별 운동`, 단위 `회`. 월마다 시작한 세션 수를 센다. 1~12월 순서와 0회인 월을 유지한다.
현재 연도의 미래 월은 opacity 0.3이며 데이터는 0이다. 현재 월은 오늘까지의 누적이다.
모든 막대는 오렌지이며 자동 정수 눈금을 쓴다. 0회인 월의 축 라벨도 유지한다.
막대 탭이나 월 선택으로 다른 섹션의 범위를 바꾸지 않는다.

### 근력·유산소

제목 `운동 구성`. 선택 연도 세그먼트의 `durationSeconds`를 유형별로 합산한다.
비율의 분모는 근력 시간 + 유산소 시간이며 워크아웃 `totalSeconds`로 나누지 않는다.
두 값은 반올림 오차 또는 구간 없는 기록 때문에 다를 수 있다.

근력은 오렌지, 유산소는 기존 파랑이다.
범례는 `근력 75.5h (64%)`·`유산소 42.5h (36%)` 형태이며 시간은 소수 첫째 자리다.
정수 퍼센트는 근력을 반올림하고 유산소는 100에서 근력 비율을 빼 합이 100%가 되게 한다.
한 유형만 있으면 바 전체를 그 유형 색으로 채우고 두 범례는 모두 표시한다.
합이 0이면 비율을 계산하지 않고 `구성 시간이 있는 기록이 없어요`를 표시한다.
기록 3회 미만에서도 구성 데이터를 표시한다. 홈의 3회 임계값은 통계에 적용하지 않는다.

### 요일 패턴

제목 `요일 패턴`, 단위 `회`. 월~일 순서를 고정하고 세션 시작 요일별 횟수를 센다.
최댓값이 0보다 크면 그 횟수를 가진 모든 요일을 오렌지로 강조한다. 나머지는 dim 색이다.
전부 0이면 강조 요일이 없다. 같은 날 세션 둘은 해당 요일에 +2다.

### 운동 부위

제목 `운동 부위`, 단위 `회`. 부위마다 그 태그를 가진 세션 수를 센다.
한 기록의 중복 raw 태그는 한 번만 센다. 알 수 없는 태그는 기존 `bodyParts`처럼 제외한다.
여러 부위를 태그한 세션은 각 부위에 +1이므로 막대 합이 총 세션 수보다 클 수 있다.
섹션 아래에 `부위를 태그한 운동 횟수예요. 한 운동은 여러 부위에 포함될 수 있어요.`를 표시한다.

0회 부위는 제외한다. 횟수 내림차순으로 정렬하고 동률은 `BodyPart.allCases` 순서
(가슴·등·어깨·팔·하체·코어)를 따른다. 모든 유효 태그가 0건이면 섹션 전체를 숨긴다.
태깅 유도 CTA와 기록 편집 진입은 두지 않는다.

## 7. 마일스톤

선택 연도 세션 수 기준으로 `10 · 25 · 50 · 100 · 200 · 300 · 500회`를 목표로 둔다.
달성한 목표를 오름차순으로 표시하고, 아직 달성하지 않은 가장 작은 목표 하나를 잠긴 배지로 표시한다.
142회이면 `10회`·`25회`·`50회`·`100회`와 `🔒 200회 · 58회 남음`을 보여준다.
0회이면 `🔒 10회 · 10회 남음`, 500회 이상이면 잠긴 배지는 없고 달성한 목표만 보인다.

화면 라벨은 `연간 마일스톤`이다. 연도를 바꾸면 해당 연도의 달성 상태로 교체한다.
별도 영속 배지 데이터·알림·달성 애니메이션은 만들지 않는다. 삭제·수정으로 세션 수가 변하면
배지 상태도 현재 데이터로 다시 계산한다.

## 8. 빈 상태와 갱신

앱 전체에 기록이 없어도 현재 연도 선택·빈 연 잔디·0회/0분/주 0.0회 요약은 표시한다.
그 아래 `아직 운동 기록이 없어요`·`워치에서 운동을 기록하면 한 해의 흐름을 볼 수 있어요.`를 표시한다.
월별·구성·요일·부위·마일스톤 섹션은 이 경우 숨긴다.

과거 기록은 있지만 선택한 현재 연도에 기록이 없으면 동일하게 빈 잔디·0값 요약을 유지하고
`2026년에는 아직 기록이 없어요`를 표시한다. 이 경우에도 차트와 배지는 숨긴다.
기록이 한 건 이상이면 모든 기본 섹션을 표시하고 부위와 0초 구성만 각자의 규칙을 따른다.

워치 저장·import·수동 기록·삭제·부위 편집의 영속 변경이 들어오면 선택 연도를 유지한 채
전체 집계를 다시 계산한다. 다른 탭에서 편집한 태그도 통계에 반영된다.
당겨서 새로고침은 기존 `WorkoutSyncCoordinator.sync()`를 호출한다.
통계 화면은 기존 저장 기록을 읽으며 HealthKit을 직접 조회하지 않는다.
동기화 실패 알림은 기존 앱 전역 알림 경로를 따른다. 이미 보이던 통계는 유지한다.

## 9. 구현 경계와 접근성

Foundation 기반의 순수 집계 모델·빌더를 `Shared/Models/`에 둔다.
빌더는 records·선택 연도·now·calendar를 입력받아 연도 선택지, 요약, 날짜 배열,
월/요일/부위 빈도, 구성 시간, 마일스톤을 반환한다. 날짜와 시간을 주입해 경계 테스트를 한다.

통계 Feature의 ViewModel이 선택 연도와 표시 결과를 소유한다. View는 `@Query` 갱신과
앱 활성화를 전달하고 UI를 표현한다. 컴포넌트에는 값과 콜백만 넘긴다.
홈의 Feature 전용 컴포넌트를 통계에서 직접 참조하지 않는다.
잔디 집계 규칙은 공유하되 연도 그리드 배치는 홈의 26주 배치와 별도로 정의한다.

각 차트는 VoiceOver에서 월/요일/부위와 `N회`를 읽을 수 있어야 한다.
잔디는 날짜와 운동 유무·농도를 읽고, 미래·연도 밖 칸은 읽지 않는다.
연도 선택은 선택 상태를 알리며 최소 44pt 탭 영역을 확보한다.
Dynamic Type에서는 범례·배지가 줄바꿈하고 연 요약 값이 잘리지 않게 한다.
강조 색 외에도 숫자·범례·선택 상태로 의미를 전달한다.

## 10. 검증 기준

- 같은 날 2세션: 요약·월·요일은 2회, 잔디는 하루 한 칸의 합산 농도.
- 12월 31일 시작 후 새해 종료: 이전 연도에 세션 전체 귀속.
- 윤년·주 시작 변경·54열이 필요한 배치: 연도 날짜를 빠짐없이 한 번씩 표시.
- 현재 연도 미래 시각 기록: 모든 집계에서 제외. 현재 월과 미래 월 표현 구분.
