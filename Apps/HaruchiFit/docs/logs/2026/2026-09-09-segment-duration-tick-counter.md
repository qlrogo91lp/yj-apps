# 구간 시간이 "0분" 으로 나온 문제

작성일: 2026-09-09
증상 보고: 실기기 검증 중 — "운동 종료 후 유산소랑 근력운동 운동시간이 측정이 안 된다"

## 증상

W2 요약 화면에서

- 맨 위 **총 시간은 정상** (예: `40:12`)
- 그 아래 **종목별 줄은 "근력 0분"** — 40분을 운동해도 몇 초로 잡혔다

시뮬레이터에서는 재현되지 않았다.

## 근본 원인

두 값이 **서로 다른 시계**로 재지고 있었다.

| 값 | 출처 | 성격 |
|---|---|---|
| 요약 총 시간 | `stopWorkout()` 의 `Int(Date().timeIntervalSince(start))` | 벽시계 |
| 구간 시간 | `session.elapsedSeconds` 의 차이 | **1초 `Timer` 틱 카운터** |

`WorkoutSessionService.elapsedSeconds` 는 `Timer.scheduledTimer` 가 1초마다 `+= 1` 하는 값이다.
실기기에서 손목을 내리거나 화면이 꺼지면 런루프 타이머가 멈추고, **다시 켜져도 밀린 만큼
따라잡지 않는다.** 그래서 화면이 켜져 있던 몇 초만 쌓였다.

`closeOpenSegment` 는 길이가 0이면 구간을 버리므로, 몇 초라도 쌓였을 때는 구간이 만들어지고
`seconds / 60` 이 0이 되어 "근력 0분" 으로 보였다.

## 왜 못 잡았나

- **시뮬레이터** — 앱이 계속 앞에 떠 있어 틱이 벽시계와 거의 같게 쌓인다
- **테스트** — `WorkoutSessionService` 가 HealthKit 을 직접 만져 테스트에서 돌릴 수 없다.
  그래서 구간 관련 테스트가 전부 미리 만든 픽스처(`RecordFixture`)를 썼고, **`closeOpenSegment`
  경로를 덮는 테스트가 하나도 없었다**

## 고친 것

구간 계산을 `WatchApp/Features/Workout/SegmentTracker.swift` 로 뺐다.

- 시계(`() -> Date`)를 주입받아 **HealthKit 없이 시간을 직접 돌려 검증**할 수 있다
- 세션 시작 시각(`startedAt`)의 단일 소스이기도 하다 — 뷰모델이 따로 들고 있지 않는다
- 테스트 5개: 벽시계 길이 · 전환 경계 · 길이 0 버리기 · **구간 합계 = 총 경과시간** · reset

## 남겨 둔 것

**일시정지 시간은 구간에도 총 시간에도 포함된다.** 한쪽만 빼면 구간 합계가 총 시간과 안 맞는다.
빼려면 둘을 함께 바꿔야 한다.

**컴플리케이션 스냅샷의 `elapsedSeconds` 는 그대로 뒀다.** 그쪽은 일시정지를 빼고 재려고
일부러 틱을 쓰는 설계다 (`WorkoutSnapshot` 주석). 벽시계로 바꾸면 그 의도가 깨진다.
경과시간을 그리는 것은 `.accessoryRectangular` 패밀리뿐이라 당장 눈에 띄지도 않는다.

**같은 틱 카운터를 화면에 그대로 쓰는 곳이 남아 있다** — 하루치 운동 중 화면의 큰 시간,
그리고 골프·Ralli 워치의 경과시간 표시. 손목을 내렸다 올리면 실제보다 뒤처져 보일 것이다.
`Packages/YJKit` 변경이라 3개 앱에 걸리므로 별도로 다룬다 (루트 `TODO.md`).
