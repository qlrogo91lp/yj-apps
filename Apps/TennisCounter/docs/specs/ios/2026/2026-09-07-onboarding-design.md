# iOS 온보딩 설계

2026-09-07 확정. 관련 플랜: [2026-09-07-onboarding.md](../../../plans/ios/2026/2026-09-07-onboarding.md)

## 목적

사용자가 **있는지도 모르고 지나치는 기능**을 첫 실행에 알린다. 설득이 아니라 안내다 — 3초 훑고 닫아도 "크라운으로 점수가 들어간다" 는 남아야 한다.

강조 3개는 **그림으로**, 나머지는 **한 장 목록으로**. 그림이 필요한 기능은 글로 설명하면 안 와닿는 것들이다 — 크라운 회전, 건강 앱에 쌓이는 워크아웃, 인스타 스토리에 올라간 카드.

## 페이지

| # | 형식 | 제목 (ko) | 본문 (ko) | 그림 |
|---|---|---|---|---|
| 1 | 스크린샷 | 크라운으로 점수 입력 | 워치에서 크라운을 위로 돌리면 내 점수, 아래로 돌리면 상대 점수. 탭해도 됩니다. | 워치 점수 화면 + **런타임 화살표 오버레이** |
| 2 | 스크린샷 | 건강 앱에 기록됩니다 | 경기마다 테니스 워크아웃으로 저장됩니다. 칼로리·심박·시간이 건강 앱에 쌓입니다. | 건강 앱의 Ralli 워크아웃 상세 |
| 3 | 스크린샷 | 인스타 스토리로 공유 | 기록 상세에서 한 번에. 카드는 스티커라 사진 위에 자유롭게 놓을 수 있습니다. | 스토리 편집기에 카드 스티커 |
| 4 | 목록 | 그리고 이런 것도 | (아래 4행) | SF Symbol |

4페이지 목록 행:

| 아이콘 | 제목 | 한 줄 |
|---|---|---|
| `applewatch.radiowaves.left.and.right` | 어느 쪽에서 시작해도 | 폰과 워치 중 먼저 시작한 쪽이 심판, 다른 쪽은 따라옵니다 |
| `arrow.uturn.backward` | 되돌리기는 끝까지 | 게임·세트 경계를 넘어 경기 시작까지 되돌립니다 |
| `lock.iphone` | 잠금화면에서 점수 확인 | Live Activity 와 워치 컴플리케이션 |
| `pause.circle` | 폰에서 일시정지 | 워크아웃 탭에서. 워치가 함께 멈춥니다 |

영문은 플랜의 문자열 표에 있다.

## 형식

- `TabView(.page)` 4장, 하단 페이지 인디케이터
- 1~3 페이지: 우상단 **건너뛰기**, 하단 **다음**
- 4 페이지: 하단 **시작하기** — 닫으면서 플래그 저장
- 건너뛰기도 플래그를 저장한다. 강제로 다시 보여주지 않는다
- 앱이 다크 고정(`MainTabView` 의 `.colorScheme(.dark)`)이라 온보딩도 검정 배경 + 브랜드 색 버튼. `LaunchScreenView` 에서 이어지는 톤

## 노출 규칙 — "봤나" 가 아니라 "몇 번째까지 봤나"

```
OnboardingView.version = 1          // 내용이 바뀌면 올린다
UserDefaults "onboardingSeenVersion" // 기본 0
표시 조건: seenVersion < version
닫을 때:  seenVersion = version
```

| 사용자 | 저장값 | 결과 |
|---|---|---|
| 새 설치 | 0 | 뜸 |
| 1.1.7 에서 업데이트 | 0 | **뜸** — 이번 출시의 새 기능(크라운·공유)을 봐야 할 사람이 기존 사용자다 |
| 이번 버전에서 봄 | 1 | 안 뜸 |
| 다음 출시에서 내용 수정 + `version = 2` | 1 | 다시 뜸 — What's New 역할 |

- 저장소는 `UserDefaults.standard`. iCloud 동기화 안 함 — 기기마다 한 번이 자연스럽다
- 삭제 후 재설치 → 0 → 다시 뜸. 정상
- 설정 페이지(작업 #8)의 "사용법 다시 보기" 는 같은 뷰를 재사용하되 플래그를 건드리지 않는다

## 진입 위치

`TennisCounterApp` — `LaunchScreenView` 가 끝난 직후, `MainTabView` 앞.

```
isLaunching → LaunchScreenView
    ↓
seenVersion < version → OnboardingView(onFinished: seenVersion = version)
    ↓
MainTabView
```

`MainTabView` 위에 시트로 띄우지 않는다 — 시트는 아래로 당겨 닫히고, 그러면 플래그가 안 남는다.

## 플랫폼 — iOS 만

워치엔 온보딩을 두지 않는다. 화면이 좁고, 워치 사용자는 거의 항상 폰 앱을 먼저 연다. 워치에서 안내할 것(크라운)은 1페이지가 폰에서 보여준다. 컴플리케이션으로 워치만 쓰고 폰 앱을 한 번도 안 연 사용자는 폰을 열 때 본다.

## 스크린샷 — ko/en 두 벌

세 스크린샷 모두 글자가 들어간다 (워치 "나/상대", 건강 앱 UI, 카드 라벨). 에셋 카탈로그의 **이미지 로컬라이즈**로 언어별 파일을 둔다. 코드는 `Image("OnboardingHealth")` 하나, 언어 선택은 시스템이 한다.

| 에셋 | 출처 | 찍는 방법 |
|---|---|---|
| `OnboardingCrown` | 워치 시뮬레이터 점수 화면 | `xcrun simctl io <UDID> screenshot`. 화살표는 이미지에 그리지 않고 **SwiftUI 가 런타임에 오버레이** — 그래야 화살표 옆 라벨이 문자열 카탈로그로 로컬라이즈되고, 이미지는 한 벌로 끝날 수도 있다 (워치 화면의 "나/상대" 라벨 때문에 두 벌 유지) |
| `OnboardingHealth` | 실기기 건강 앱 | 실제 경기 저장 후 건강 앱 → 운동 → Ralli 항목 상세 |
| `OnboardingShare` | 실기기 인스타그램 | 작업 #1 구현 후. 스토리 편집기에 카드 올린 상태. 개인 사진 대신 단색 배경 |

## 의존 관계

- **#1 공유 버튼** — 3페이지 스크린샷의 원본
- **#4 크라운** — 1페이지가 안내하는 기능. 기능 없이 안내부터 나가면 안 된다
- 따라서 온보딩은 이번 출시 항목 중 **맨 뒤**. 코드 뼈대는 먼저 만들 수 있고, 이미지만 나중에 끼운다

## 하지 않는 것

- 스와이프 카드에 일러스트 — 스크린샷으로 충분하고 디자인 작업이 별도로 붙는다
- 모드 옵션(No-Ad·타이브레이크) 설명 — 온보딩이 아니라 모드 선택 화면의 ⓘ 자리. 별도 작업
- 권한 프롬프트 선요청 — HealthKit 권한은 지금처럼 첫 경기 시작 때
- 애니메이션·인터랙션 — 정적 이미지. 나중에 원하면 1페이지만 크라운 회전 애니메이션으로 교체
